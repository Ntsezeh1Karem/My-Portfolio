# Portfolio – Ntsezeh Besipah Karem
Static portfolio site (HTML, CSS, JS). Edit projects and skills at the top of `script.js`.

## Publish on GitHub Pages
1. On GitHub, create a public repo named exactly `Ntsezeh1Karem.github.io`.
2. In this folder run:
   git init && git add . && git commit -m "Initial portfolio"
   git branch -M main
   git remote add origin https://github.com/Ntsezeh1Karem/Ntsezeh1Karem.github.io.git
   git push -u origin main
3. Repo Settings > Pages > Deploy from branch > main / root. Live at https://Ntsezeh1Karem.github.io in a minute or two.

## Update later
Edit `script.js`, then: git add . && git commit -m "Add project" && git push
